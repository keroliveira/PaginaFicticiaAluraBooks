# Pagina Ficticia AluraBooks
Projeto desenvolvido durante os estudos de **HTML e CSS**, com foco na construção de uma página web responsiva para uma livraria fictícia. A interface apresenta livros em destaque, seções de recomendações, tópicos relacionados à leitura e uma área de contato para newsletter. O projeto também utiliza carrosséis interativos para a navegação entre os livros.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- [Swiper.js](https://swiperjs.com/): biblioteca utilizada para implementar os carrosséis.
- Google Fonts: tipografia personalizada.

## Conceitos praticados
- Estruturação de páginas com HTML semântico.
- Estilização e organização de componentes com CSS.
- Uso de variáveis CSS para padronização de cores e fontes.
- Flexbox e organização de elementos na interface.
- Responsividade com media queries.
- Criação de menus interativos com HTML e CSS.
- Implementação e configuração de carrosséis com JavaScript e Swiper.js.
- Organização do CSS em seções comentadas, reunindo os estilos em um único arquivo.
- Utilização de imagens, ícones, links e campos de formulário.

## Responsividade
O layout utiliza media queries para adaptar a apresentação dos elementos a diferentes tamanhos de tela, incluindo dispositivos móveis, tablets e desktops.
